# Changelog

## 1.0.0

- New windows with rounded cards, the logo and light and dark themes
- Video: rotate, remove sound, extract subtitles
- PDF: merge, split, compress, recognize text
- E-books: EPUB, MOBI, AZW3, PDF, TXT
- Images: HEIC and camera RAW files as a source
- Menus of missing tools stay hidden, optional tools are suggested
- The installer can turn the classic context menu on in Windows 11
- Tools are found right after installation, without a new terminal
- A clear message when ffmpeg lacks an encoder
- Several read-only PDFs or images can be converted at once
- Two conversions of the same file at once no longer lose a result
- The installer shows the logo when it is done
